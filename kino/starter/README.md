# Первый ролик без AI

Учебный ролик: 15 секунд, 1080×1920, 30 кадров/с, без звука. HTML + HyperFrames 0.8.208, GSAP 3.15.0. Сцены написаны для этого гайда.

1. Установите Node.js 22+ с https://nodejs.org/ и FFmpeg по https://ffmpeg.org/download.html . Закройте и заново откройте терминал после установки.
2. Откройте терминал в этой папке (в ней package.json). Проверьте `node --version` и `ffmpeg -version`.
3. `npm run dev` — локальный предпросмотр. Откройте адрес, который напечатает программа. Остановить: Ctrl+C.
4. `npm run check` — проверка композиции.
5. `npm run render` — MP4 появится в `output/first-video.mp4`. Первый запуск npx скачает HyperFrames и может скачать браузер для рендера; нужен интернет. AI-аккаунт, GPU и модели не нужны.

Для другого текста откройте compositions/hook.html, test.html, takeaway.html в текстовом редакторе. Меняйте текст внутри h1 и p, не теги. Сохраните, проверьте предпросмотр и повторите render. Более длинный текст может не поместиться.

Исходный код самого примера: MIT, см. LICENSE.txt. GSAP и шрифт Onest имеют отдельные лицензии в assets/. Никакие сторонние материалы, голоса и модели в архив не входят.
