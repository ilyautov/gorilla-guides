Все восемь ссылок из карусели, что каждый делает, какая лицензия и команда установки. Звёзды и лицензии сняты с GitHub 25.10.2026. Пять из восьми (HyperFrames, LTX, Depth Anything, OmniVoice, WhisperX) работают в конвейере наших роликов.

0С чего начать, если ни разу не делал видео кодом

  1. Поставь Claude Code и Node.js 22+.
  2. Поставь плагин HyperFrames (команда в шаге 1) и открой Claude Code в пустой папке.
  3. Попроси один короткий ролик: тема, длина, формат. Например промптом ниже.
  4. Когда первый MP4 получится, добавляй по одному: голос (OmniVoice), субтитры (WhisperX), фото с параллаксом (Depth Anything).
Сделай вертикальный ролик 1080×1920 на 15 секунд через HyperFrames.
Тема: [о чём ролик]. Три сцены, крупный текст, который читается на телефоне.
Без озвучки, с плавными переходами. В конце отрендери MP4 и покажи,

Полный разбор нашего конвейера со схемами и стартовым кодом: «Фабрика рилсов на Claude Code».

1HyperFrames

github.com/heygen-com/hyperframes · ★ 71,6K

Пишешь HTML, CSS и анимации, движок рендерит MP4. Сделан под агентов: для Claude Code, Codex и Cursor есть плагин и скиллы. На нём стоит конвейер роликов этого канала.

Лицензия: Apache-2.0.

claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

2Remotion

github.com/remotion-dev/remotion · ★ 67,2K

Ролик пишется как React-компонент и рендерится в MP4. У команды есть официальные скиллы для агентов (субтитры, рендер, студия).

Лицензия: Remotion License: бесплатно частным лицам, компаниям до 3 сотрудников и некоммерческим; остальным нужна платная лицензия.

npx create-video@latest
npx skills add remotion-dev/skills

3claude-code-video-toolkit

github.com/digitalsamba/claude-code-video-toolkit · ★ 2,3K

Рабочая папка для Claude Code: команда /video ведёт от сценария до MP4 (озвучка, музыка, картинки, монтаж). Тяжёлые открытые модели запускаются на облачном GPU (автор советует Modal), пример hello-world рендерится без ключей.

Лицензия: MIT.

git clone https://github.com/digitalsamba/claude-code-video-toolkit.git
cd claude-code-video-toolkit
claude
# внутри Claude Code: /setup, потом /video

4Manim

github.com/3b1b/manim · ★ 95,6K

Движок, который автор 3Blue1Brown написал для своих роликов: формулы, графики и схемы, анимированные кодом на Python. Есть и общественная версия ManimCommunity/manim, их установки не смешивайте.

Лицензия: MIT.

pip install manimgl

5LTX-2

github.com/Lightricks/LTX-2 · ★ 9,9K

Открытая модель, которая генерирует видео сразу со звуком: по тексту, картинке или аудио. Веса около 66 ГБ, нужна мощная машина.

Лицензия: LTX-2.x Community License: бесплатно, пока годовая выручка компании меньше $10 млн.

git clone https://github.com/Lightricks/LTX-2.git
cd LTX-2
uv sync --extra natten

6Depth Anything V2

github.com/DepthAnything/Depth-Anything-V2 · ★ 9,0K

Карта глубины по одной картинке. Режешь фото на слои по глубине, и камера пролетает между ними: параллакс вместо плоского наезда.

Лицензия: Small — Apache-2.0; Base, Large и Giant — CC-BY-NC-4.0 (только некоммерчески).

git clone https://github.com/DepthAnything/Depth-Anything-V2
cd Depth-Anything-V2
pip install -r requirements.txt

7OmniVoice

github.com/k2-fsa/OmniVoice · ★ 15,8K

Клон голоса по образцу 3–10 секунд, 600+ языков, русский тоже. Мы выбрали его в слепом тесте шести моделей озвучки.

Лицензия: код Apache-2.0; веса модели мы используем как некоммерческие, проверьте условия на странице модели перед монетизацией.

pip install omnivoice

8WhisperX

github.com/m-bain/whisperX · ★ 24,8K

Расшифровка речи с временем каждого слова. Из этого собираются субтитры по словам, как в рилсах. Работает локально.

Лицензия: BSD-2-Clause.

pip install whisperx

9Честно о подвохах

  • «Бесплатно» значит бесплатный код. Нейросетевым моделям (LTX-2, OmniVoice, Depth Anything) нужна мощная видеокарта или Mac с большим объёмом памяти, иначе облако за деньги.
  • Лицензии разные. Remotion и LTX-2 бесплатны не для всех компаний, у части весов Depth Anything и OmniVoice есть ограничения на коммерцию. Перед монетизацией перечитайте лицензию сами.
  • Клонировать можно только свой голос или голос человека, который дал согласие.
  • Агент пишет код ролика, но вкус и проверка остаются на вас: первые ролики почти всегда выглядят как слайды.
