Инструкция к ролику @gorilla_under_hood

Своя колонка на Claude

Говорите с Маком голосом, отвечает Claude. Речь в текст переводится на самом Маке, звук никуда не уходит. Наружу отправляется только текст вопроса.

бесплатный кодзвук не уходит с Макасистемные настройки не трогает

0Что нужно

  • Mac. Проверяли на Apple Silicon. Голос ответа берётся из встроенного в macOS say, поэтому на Windows и Linux скрипт в таком виде не заработает.
  • Подписка Claude (Pro или Max) и установленный Claude Code. Один раз запустите в Терминале claude и войдите своим аккаунтом. API-ключ не нужен. Если Claude Code уже стоит, обновите его командой claude update: скрипт использует свежие флаги.
  • Python 3 (на Маке есть, при первом запуске macOS может предложить поставить «инструменты разработчика», согласитесь) и около 1 ГБ места под модели.

1Скачать и установить, 5 минут

Скачать kolonka.zip

Распакуйте, например, в ~/kolonka, и в Терминале:

cd ~/kolonka
./setup.sh

setup.sh ставит всё внутрь этой папки: отдельное окружение Python, модель Vosk для слова «Горо» (45 МБ) и модель распознавания Whisper small (около 460 МБ, ложится в кэш ~/.cache/huggingface). Больше всего времени уходит на скачивание. Удалить всё: стереть папку и ~/.cache/huggingface/hub/models--Systran--faster-whisper-small.

Код по файлам: kolonka.py, prompt.txt, setup.sh, run.sh, requirements.txt.

2Запустить

./run.sh --text "Привет, ты кто?"

Это проверка без микрофона: должен прозвучать ответ. Дальше два режима.

  • По кнопке. ./run.sh: Enter, говорите, Enter. Самый надёжный.
  • По слову. ./run.sh --wake: скажите «Горо», после щелчка задайте вопрос. Конец вопроса это секунда тишины. Можно и слитно: «Горо, сколько лап у паука?»
Если пишет «микрофон отдаёт ровные нули». macOS не дал доступ. Системные настройки → Конфиденциальность и безопасность → Микрофон → включите Терминал (или iTerm, VS Code, откуда запускаете). Полностью закройте его через Cmd+Q, откройте и запустите снова. При первом запуске macOS может спросить сам: нажмите «Разрешить».

Если по умолчанию выбраны AirPods, macOS переключает их в режим гарнитуры, и распознавание хуже. Лучше выбрать встроенный микрофон: Настройки → Звук → Вход.

3Промпт: характер колонки

Лежит в prompt.txt, меняйте как хотите: имя, тон, длину ответа.

Ты голосовая колонка по имени Горо. Твой ответ зачитают вслух.
Отвечай по-русски, коротко: одно-два предложения, разговорным языком.
Без списков, markdown, эмодзи и ссылок.
У тебя нет интернета, часов, таймеров, музыки и умного дома. Если просят такое, скажи это в одной фразе и предложи, чем помочь словами.
Не выдумывай свежие новости, погоду на сегодня и курсы валют. Не обещай того, чего не сможешь сделать сам, например напомнить позже.

4Что куда уходит

  • Звук с микрофона никуда. Он обрабатывается в памяти и не пишется на диск. В режиме «Горо» микрофон включён всё время, но слушает его локальная модель Vosk.
  • Текст вопроса и три прошлых вопроса с ответами (чтобы работало «а ещё?») уходят в Anthropic через Claude Code, по вашей подписке. Как Anthropic хранит переписку, смотрите в claude.ai → Настройки → Конфиденциальность (пункт про помощь в улучшении Claude).
  • Ответ озвучивается на Маке, временный файл сразу удаляется.
  • У Claude нет ни одного инструмента: он не может запускать команды, читать файлы и ходить в интернет. Ваши CLAUDE.md, плагины и MCP не подключаются. Телеметрия Claude Code выключена.

Честно: трафик мы снифером не снимали. «Звук не уходит» следует из кода, его можно прочитать: это один файл.

×Честные ограничения

  • Задержка около 5 секунд от конца вопроса до начала ответа (замер на Маке с Apple Silicon: распознавание 0,8 с, Claude 3,3 с, голос 0,9 с; иногда Claude думает до 10 с).
  • Это не умный дом. Таймеров, будильников, музыки, света и интернета нет. Погоду на сегодня и новости он не знает и так и скажет.
  • Нужен Mac и подписка Claude. Каждый вопрос немного расходует лимит подписки.
  • Слово «Горо» модель слышит как «гора», поэтому колонка проснётся и на «гору» в разговоре. Надёжнее режим по кнопке.
  • Голос встроенный, Milena из macOS: понятный, но роботный.
  • Пока колонка говорит, она не слушает: перебить нельзя.
  • Офлайн не работает: без интернета Claude не ответит.

Из чего собрано

  • faster-whisper (MIT) и модель Whisper small (MIT): речь в текст.
  • Vosk и модель vosk-model-small-ru (Apache-2.0): слово «Горо».
  • sounddevice (MIT), numpy (BSD): микрофон.
  • Claude Code по подписке Anthropic: ответы. Голос: встроенный в macOS say.

Код колонки бесплатный, берите и меняйте. Сторонние библиотеки принадлежат их авторам.
