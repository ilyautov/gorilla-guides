Граф для Claude Code: обещали ×79, мы замерили

Graphify — бесплатный инструмент, который превращает код в граф, чтобы Claude Code спрашивал граф, а не читал файлы. В роликах пишут «в 79 раз меньше токенов». Мы поставили его на свой проект и прогнали 24 сессии с графом и без. Ниже: как поставить, наши цифры и когда граф правда нужен.

бесплатно, Apache-2.0код не уходит в облако24 сессии замерабез выдуманных цифр

1Что это

Graphify-Labs/graphify: открытый проект на Python, лицензия Apache-2.0, около 136 тысяч звёзд на GitHub (27.10.2026). Пакет на PyPI называется graphifyy, с двумя «y». Остальные graphify* к нему не относятся.

  • Что строит. Разбирает код через tree-sitter (около 40 языков) и собирает граф: файлы, функции, классы, кто кого вызывает и импортирует. Для кода не нужны ни нейросеть, ни интернет, всё считается у вас на компьютере. Документы, PDF и картинки он уже отдаёт в нейросеть, но это можно выключить.
  • Что получаете. Папку graphify-out/: graph.json (граф), GRAPH_REPORT.md (главные узлы и модули) и graph.html (кликабельная картинка).
  • Как его использует Claude Code. В CLAUDE.md дописывается правило «сначала graphify query, потом поиск и чтение файлов», и ставятся хуки, которые перед поиском и чтением напоминают про граф.

2Как поставить

Нужны Python 3.10+ и uv. Мы ставили в отдельное окружение внутри проекта, без глобальных установок, вот эти команды:

uv venv --python 3.12 .graphify-venv
uv pip install --python .graphify-venv/bin/python graphifyy
export PATH="$PWD/.graphify-venv/bin:$PATH"
graphify --version

Так советует README (мы этот вариант не запускали, он ставит команду для всего пользователя):

uv tool install graphifyy

Построить граф только по коду, без нейросети и без ключей. На нашем проекте это заняло 5 секунд:

cd ваш-проект
GRAPHIFY_BACKEND=none graphify extract . --code-only
GRAPHIFY_BACKEND=none graphify cluster-only . --no-label

Подключить к Claude Code в этом проекте: правило в CLAUDE.md, хуки в .claude/settings.json и скилл /graphify в .claude/skills/:

graphify claude install
graphify install --project

Спросить граф самому:

graphify query "где считается время начала реплики"
graphify explain "envelope"
graphify path "main" "setJaw"

Убрать всё: graphify claude uninstall или graphify uninstall --purge (вместе с папкой graphify-out/).

Хуки ссылаются на команду graphify по имени. Если она есть только в вашем окружении, а не в PATH, хук не сработает. Либо добавьте окружение в PATH, либо пропишите в .claude/settings.json полный путь к graphify.
Каждый запрос graphify query по умолчанию пишется в журнал ~/.cache/graphify-queries.log: вопрос и сколько узлов нашлось. Отключить: export GRAPHIFY_QUERY_LOG_DISABLE=1.

3Наш замер

Взяли код нашего движка 3D-скетчей: 32 файла (JavaScript и Python), 367 КБ. Граф построился за 5,5 секунды: 302 узла, 1045 связей. Задали Claude Code шесть настоящих вопросов о коде: где считается старт реплики, какие действия у персонажа, как устроен рендер, как работает синхрон рта, какие бывают планы камеры, и «опиши архитектуру целиком». Каждый вопрос по два раза в обычной сессии и по два раза с подключённым Graphify. Токены брали из отчёта самого Claude Code (claude -p --output-format json).

На вопросе про архитектуру новых токенов с графом стало на 24 % меньше: 34 тысячи вместо 44. Это единственный вопрос, где граф дал заметную экономию. Качество ответов одинаковое: все 24 ответа верные, со ссылками на нужные строки кода. Один раз Claude без графа пропустил четыре действия персонажа, с графом нашёл все.

Почему не ×79. Claude Code и без графа не читает проект целиком: он ищет по словам и открывает только нужные куски. В наших сессиях весь код не прочитали ни разу. Граф не отменяет чтение файлов, потому что Claude нужны строки кода для ответа. Запрос к графу просто добавляет 3–6 КБ сверху. Встроенный тест Graphify (graphify benchmark) на нашем графе показывает «в 16,9 раза меньше», но сравнивает он с чтением всех файлов подряд, а так Claude не работает.

Сырые данные, скрипт замера и вопросы лежат в нашем рабочем репозитории. Ограничения: один проект на 32 файла, одна модель, по два прогона на вопрос. Разброс между двумя одинаковыми прогонами доходил до 1,8 раза.

4Когда граф помогает, а когда нет

  • Помогает: вопросы «как всё устроено», первое знакомство с чужим большим репозиторием, поиск всех мест, где используется функция, картинка связей для себя (graph.html).
  • Не помогает: точечные вопросы «где считается X» в проекте, который Claude находит поиском по словам. Там граф только добавляет шаг.
  • Не мерили: монорепо на сотни и тысячи файлов, где обычный поиск выдаёт горы совпадений. Там эффект может быть больше, проверьте на своём проекте.
  • Как проверить у себя: задайте один и тот же вопрос в двух сессиях, с графом и без, через claude -p "вопрос" --output-format json и сравните поле usage.

5Лицензия и облако

Код Graphify открыт под Apache-2.0: можно пользоваться бесплатно, в том числе в работе, менять и встраивать, если сохранить уведомление о лицензии. Рядом есть платный Graphify Cloud с пробным периодом. Обещание «на 80 % меньше токенов» в README относится к нему, мы его не проверяли. Для графа по коду облако не нужно.
