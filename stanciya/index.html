Разбор к ролику @gorilla_under_hood

Станция из-за одной цифры

Слабый ключ в чужом сертификате помог энтузиастам получить доступ к системе Яндекс Станций. Яндекс выпустил патч, но история на этом не закончилась: сообщество описало откат и другие способы для отдельных моделей. Здесь разбираем, что случилось и чем сейчас пользуются.

обновлено 27.10.2026ссылки на проектысовместимость зависит от модели
Апдейт от 27 октября. Первая версия слишком широко трактовала патч: будто модификации больше недоступны. Ниже добавлены актуальные инструменты и ограничения по документации проектов. На физических колонках эти сценарии мы не тестировали.

1Что вообще случилось

Чтобы устройства доверяли серверу, у сервера есть цифровой «паспорт»: сертификат, подписанный удостоверяющим центром. Секретный ключ должен выбираться из огромного диапазона случайных чисел. У восьми промежуточных сертификатов центра eMudhra ключи оказались крошечными: 4, 56, 66 и ещё пять значений меньше 256. Их можно восстановить из публичных сертификатов и подписывать поддельные «паспорта» для клиентов, которые ещё доверяют этой цепочке. Разбор с проверкой ключей.

17 октября 2026 года исследователь сообщил о проблеме браузерным компаниям и eMudhra. Firefox заблокировал сертификаты в тот же день, позже последовали другие обновления доверия. Хронология и ответы удостоверяющего центра есть в отчёте Mozilla.

2При чём тут колонка

Прошивка Станции ещё доверяла скомпрометированной цепочке. Энтузиасты заставили колонку принять свой сервер за сервер Яндекса и передали конфигурацию, включающую ADB, интерфейс отладки. В README eQuasar первым проверенным устройством указана Мини 2 со сборкой от 13 октября 2026 года. Зеркало исходников eQuasar, автор проекта bitracker.

ADB и root нужно различать. ADB даёт соединение с устройством; права суперпользователя root позволяют менять систему. В документации сообщества результат проверяют по uid=0(root). Сам по себе открытый порт ещё не означает полный доступ.

3Чем сейчас взламывают Станции

Состояние на 27 октября 2026 года. Ниже указано, что делают проекты и какие проверки описывают их авторы. Единой программы для всех Станций и прошивок нет.

eQuasar: исходный способ

Конфигурация Nginx, сертификаты и подмена DNS. Совместимая прошивка получает от подставного сервера настройки с включённым сетевым ADB. Это основа истории со слабым ключом. После обновления доверенных сертификатов прежний сценарий может перестать работать. Код и README.

quasar-unlock: сервер разблокировки

Проект с веб-сервером на Hono и модулем Nix. В коде есть ответы для активации ADB и подбора обновления по платформе и текущей версии. Это автоматизация серверной части; наличие модели в списке прошивок ещё не подтверждает успешный взлом. Репозиторий · гайд сообщества по сетевому доступу.

lite-kit: свой стенд на компьютере

Локальные DNS и HTTPS для Windows, Linux и macOS, включение ADB и выдача выбранной прошивки. В README заявлены успешные проверки на Лайт 1, Мини 1, Миди и Мини 2. Для Мини 2 точная версия не зафиксирована. В вики отдельно описан проход на обновлённой Лайт 1: заводской образ принимает более старую прошивку, после чего появляется root. Это результат для конкретной модели, а не обещание отката любой Станции. Репозиторий и список проверок · описание локального стенда.

Лайт 2 и Мини 3: через заводской режим

Для этих моделей опубликованы отдельные способы после октябрьского патча. Через заводской режим меняют набор доверенных сертификатов основной системы; затем используется сервер типа eQuasar. Для Мини 3 нужны дополнительные настройки ADB и Wi-Fi. Успех зависит и от сохранённого заводского образа: если он тоже обновлён, описанный путь для Мини 3 не подходит. Гайд для Лайт 2 · отдельный гайд для Мини 3.

AliceBridge: с Android-телефона

Приложение поднимает точку доступа, настраивает DNS и подключается встроенным ADB. Основной режим использует root телефона или временный root через DFRoot; совместимость зависит от ядра телефона. Вики сообщает о проверках на Лайт 1, Мини 1, Миди и Лайт 2. Для Станции первого поколения предусмотрен отдельный путь с записью boot-образа. Режим через Shizuku без root телефона пока экспериментальный: полный проход с реальной колонкой не подтверждён. Описание, требования и ограничения.

yasta_flasher: отдельная история для Макс

Windows-утилита для Станции Макс на Amlogic S905X2: чтение и запись разделов, работа с загрузчиком и образами. Требует сервисного USB-подключения к плате. Это уже вмешательство в железо; переносить сюда инструкции от Лайт или Мини нельзя. Код и требования.

А что ставят после получения доступа? Например, YAM: менеджер приложений и модулей в формате .yap. Его установщик использует уже работающий ADB. Получение доступа и установка дополнительного софта остаются разными этапами.

4Что тогда закрыл патч

22 октября Яндекс сообщил о подготовленном обновлении безопасности и начале его распространения. Заявление компании в «Коде». Штатная Станция проверяет обновления автоматически и обычно устанавливает их ночью, согласно справке Яндекса.

Обновление мешает исходной подмене сервера на исправленной прошивке. Но на части моделей сообщество использует старый заводской образ, откат либо изменение доверенных сертификатов. Поэтому фраза «колонка была в сети, значит её уже никак не открыть» неверна. Нужны точная модель, версия основной прошивки и состояние заводского образа.

Обычный сброс настроек и гарантированный откат прошивки тоже нельзя считать одним действием: поведение различается между моделями. Проверять его нужно по документации конкретного устройства.

5Что даёт доступ и чем рискуете

Root позволяет запускать свой софт и менять систему. Для замены Алисы ещё нужно наладить микрофоны, звук, распознавание и ответы выбранного помощника. Командная оболочка сама по себе не превращает колонку в готовую автономную нейросеть и не даёт бесплатную подписку Плюс.

  • Потеря данных и нерабочая колонка. Сброс стирает настройки, а ошибка при записи системных разделов может потребовать аппаратного восстановления. Чужой boot-образ нельзя считать подходящим только из-за похожего названия модели.
  • Открытый доступ по сети. Незащищённые ADB и SSH дают доступ другим участникам сети. Их нельзя выставлять в интернет.
  • Зависимость от чужого сервера и скриптов. Публичный сервер разблокировки получает перенаправленные запросы колонки. Перед запуском утилит стоит прочитать код и понимать, что меняется на компьютере, телефоне и Станции.
  • Обновления. В гайдах часто предлагают отключить автоматические обновления ради сохранения доступа. Вместе с ними перестают приходить штатные исправления безопасности.

Речь здесь о модификации собственной колонки. Получение root не подтверждает снятие ограничений устройства по подписке или рассрочке.

  • Нужна обычная Алиса? Оставьте штатную прошивку и автоматические обновления.
