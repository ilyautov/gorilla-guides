Станция из-за одной цифры

Как получить root на своей Яндекс Станции через lite-kit: выбрать прошивку, настроить DNS и зайти в систему с компьютера.

Сброс удалит настройки колонки. Во время записи прошивки не отключайте питание. ADB на порту 5555 не выставляйте в интернет.

1Выберите свою модель

  • Лайт 1 и Мини 1: инструкция ниже, с конкретными сборками.
  • Мини 2 и Миди: у авторов lite-kit есть успешные проходы, но здесь нет точной пары «модель + сборка». Начните с списка проверок.
  • Лайт 2: замена сертификатов через заводской режим.
  • Мини 3: свой способ через заводской образ. Если он тоже обновлён, этот путь не подходит.
  • Станция 1: AliceBridge и отдельный boot-образ.
  • Макс: yasta_flasher, сервисный USB и работа с платой.
  • Другая модель: найдите её в каталоге устройств.

2Подготовьте компьютер

Нужны роутер со сменным DNS, компьютер и приложение «Дом с Алисой». Телефон, компьютер и колонка должны быть в одной локальной сети без изоляции клиентов.

Скачайте архив lite-kit, распакуйте и откройте терминал в его папке. Все дальнейшие команды выполняются оттуда.

Windows 10/11

Установите Python 3 с добавлением в PATH и Google Platform-Tools. Папку с adb.exe тоже добавьте в PATH. Затем откройте PowerShell от имени администратора в папке lite-kit и используйте это окно до конца настройки.

Разрешите запуск скриптов в текущем окне и проверьте инструменты:

Get-ChildItem -File -Filter *.ps1 | Unblock-File
Set-ExecutionPolicy -Scope Process RemoteSigned
python --version
adb version
macOS

Нужен Homebrew. Затем:

brew install python openssl dnsmasq
brew install --cask android-platform-tools
chmod +x start.sh stop.sh
adb version
Ubuntu / Debian 
sudo apt update
sudo apt install python3 openssl dnsmasq dnsutils adb
chmod +x start.sh stop.sh
adb version

3Скачайте нужную прошивку

Выберите свой образ и сохраните его в указанную папку внутри lite-kit. Подпапку с именем платформы создайте вручную.

Лайт 1: скачать прошивку. Сохранить как:

firmware/yandexmicro/0.369.1.46.4778262442.20261013.297.zip

Мини 1: скачать прошивку. Сохранить как:

firmware/yandexmini/1.305.4.16.3237824040.20250721.zip

Не распаковывайте файл и не меняйте его имя. В папке вашей платформы должен остаться только выбранный образ. При запуске lite-kit подхватит его по модели и версии.

4Запустите стенд

Windows 
.\start.ps1

Подтвердите запрос прав администратора.

macOS / Linux 
sudo ./start.sh

Скрипт напечатает адрес компьютера, например 192.168.1.50. Запишите его. Порты 53, 80 и 443 должны быть свободны.

5Сбросьте и подключите колонку

  1. Лайт 1: отключите питание, подключите снова и сразу удерживайте кнопку паузы 6–10 секунд до жёлто-зелёного индикатора.
    Мини 1: отключите питание, зажмите кнопку отключения микрофонов, подайте питание и держите кнопку около 5 секунд до жёлтого индикатора.
  2. В «Доме с Алисой» нажмите «+» → «Устройство с Алисой». Дойдите до выбора Wi-Fi, пока не нажимайте «Подключиться».
  3. На роутере сохраните прежние значения DNS. В разделе LAN / DHCP → DNS-сервер укажите адрес компьютера из шага 4. Дополнительный DNS очистите. Нужна настройка для устройств домашней сети, а не только DNS подключения WAN.
  4. Вернитесь в приложение и подключите колонку к этой сети. Не выключайте компьютер и колонку: стенд должен отдать выбранную прошивку.

Если началась перепрошивка, дождитесь её завершения и перезагрузки: в log/server.log появятся OTA-AUTO и файл отдан ПОЛНОСТЬЮ. Если нужная версия уже стоит, загрузки не будет. Дальше ищите ответ с включённым adbd.

6Зайдите и проверьте root

Найдите IP колонки в списке клиентов роутера. В примере ниже это 192.168.1.77; замените его своим адресом.

adb connect 192.168.1.77:5555
adb shell id

Нужный результат: uid=0(root). Если видите uid=2000(shell), полного доступа ещё нет.

Открыть командную оболочку:

adb shell

Выйти из неё: exit.

7Завершите настройку

Нужен постоянный доступ? До возврата DNS выполните закрепление доступа, настройку SSH и отключение OTA для своей модели. Отключение OTA убирает и штатные обновления безопасности.

Верните на роутере сохранённые значения DNS, затем остановите стенд:

Windows 
.\stop.ps1
macOS / Linux 
sudo ./stop.sh

Если вы только проверяли способ, можно закончить здесь. Без закрепления доступ может исчезнуть после перезагрузки или обновления.

?Если не получилось

  • Стенд не запускается: проверьте занятые порты 53/80/443. Не отключайте сетевые службы наугад; посмотрите ошибку в log/server.log.
  • Колонка не видит стенд: сначала проверьте DNS самого стенда командой ниже. Замените 192.168.1.50 адресом компьютера из шага 4; он же должен прийти в ответе.
nslookup quasar.yandex.net 192.168.1.50

Если стенд отвечает правильно, проверьте DNS в настройках DHCP роутера и переподключите колонку к Wi-Fi, чтобы она получила новые параметры.

  • ADB пишет Connection refused: проверьте IP колонки и журнал стенда. Если прошивка не установилась или не принимает сертификат, повторять adb connect бессмысленно.
  • Привязка застряла: верните прежний DNS, сбросьте колонку и повторите с шага 5. DNS меняйте только на экране выбора Wi-Fi.
  • Хотите прервать попытку: верните прежний DNS и выполните stop.ps1 или sudo ./stop.sh. Во время записи прошивки дождитесь завершения.

→Что поставить дальше

YAM для приложений и модулей, AirPlay для музыки или своего помощника на Claude на компьютере. Root сам по себе не заменяет Алису и не даёт бесплатный Плюс.
