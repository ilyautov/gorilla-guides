Телевизор LG или Samsung без рекламы

Так же, как с Android, не выйдет: внутри другая система. Но баннер на главном экране LG снимается за минуту, а свой чистый экран ставится как приложение.

бесплатноничего не перепрошиваетсяудаляется одной командой

0Убрать баннер LG без Claude, 1 минута

Пульт → кнопка настроек → Все настройки → Общие → Система → Дополнительные настройки → Настройки главного экрана.

  • Home Promotion / Продвижение на главной → Выкл. Верхний рекламный баннер исчезает.
  • Content Recommendation / Рекомендации контента → Выкл. Пропадают подборки «в тренде».
  • Если есть Screen Saver Promotion (реклама перед заставкой), тоже Выкл.

Названия пунктов зависят от версии webOS. Узнать версию: трижды нажать «без звука» на пульте. Путь выше взят из справки LG для webOS 6 и webOS 22.

Для Samsung проверенного пути в настройках у нас нет: меню меняется от года к году. Переходите к шагу 1.

1Свой чистый главный экран: Free My TV

Открытый проект под лицензией MIT: github.com/simbasjungles/free-my-tv, сайт freemytv.io. Тёмный экран с вашими приложениями, погодой и подборками, без рекламы. Ставится как приложение: родной экран остаётся, Free My TV открывается кнопкой с цифрой на пульте.

Что нужно: компьютер в той же сети Wi‑Fi, Python 3, по желанию Claude Code (можно и руками по README) и бесплатный ключ TMDB для подборок «в тренде» (themoviedb.org → Settings → API).

LG (webOS 3 и новее)

  1. На телевизоре откройте LG Content Store и установите приложение Developer Mode. Если его нет в магазине вашего региона, способ не сработает.
  2. Войдите бесплатным аккаунтом webostv.developer.lge.com, включите Dev Mode Status (телевизор перезагрузится), потом Key Server. Запишите IP-адрес и пароль-фразу с экрана.
  3. На компьютере: 
    git clone https://github.com/simbasjungles/free-my-tv
cd free-my-tv
  4. Откройте Claude Code в этой папке и скажите (подставьте IP и город): 
    Install Free My TV on my LG TV at 192.168.1.50. I live in Moscow.
    Claude соберёт приложение и даст команду установки. Пароль-фразу вводите сами. Руками то же самое: 
    python3 webos/build.py
python3 webos/install.py 192.168.1.50
  5. На телевизоре, пока открыт Free My TV, зажмите кнопку с цифрой на пульте. Теперь она открывает его откуда угодно.
Режим разработчика живёт около 40 дней. Раз в месяц откройте приложение Developer Mode и нажмите EXTEND, пока время не вышло. Если время кончится и телевизор перезагрузится, LG сам удалит всё, что поставлено через режим разработчика.

Удалить: python3 webos/install.py 192.168.1.50 --uninstall

Samsung (2017 и новее, Tizen 3+)

  1. На телевизоре: Приложения → на пульте наберите 1 2 3 4 5 → включите Developer mode, в Host PC IP впишите IP компьютера, перезагрузите телевизор.
  2. На компьютере скачайте TizenBrew Installer, сторонний общественный установщик: github.com/reisxd/TizenBrewInstaller. Подключитесь к телевизору.
  3. Install from GitHub → simbasjungles/free-my-tv. На телевизорах 2023 года и новее один раз попросит войти в аккаунт Samsung, чтобы подписать приложение.
  4. В настройках телевизора (Start Screen Options) включите Autorun Last App, чтобы он включался сразу в Free My TV.

Android TV и Google TV (TCL, Sony, Hisense, Philips, Xiaomi)

Там можно больше: Free My TV становится главным экраном вместо родного и отключает рекламные приложения, кнопка «Original» возвращает всё. Это способ из ролика про телевизор родителей: github.com/Gathin23/cleanyourtv и free-my-tv#install.

×Где не сработает

  • LG старше webOS 3, Samsung старше 2017 года.
  • Roku и другие системы без режима разработчика.
  • Реклама внутри приложений (YouTube, онлайн-кинотеатры) никуда не денется: это другое.

Источники: README free-my-tv, LG webOS TV Developer, справка LG «Changing home screen settings» для webOS 6 и webOS 22. Проекты не наши, спасибо авторам.
